# Maturita graduation work final assignment

#### topic: `Návrh a realizace osobní technologické infrastruktury.`

#### category: `hardware a počítačové sítě`

#### description

```
Vybudujte a zprovozněte vlastní síť zařízení, například domácí server, veřejný server a notebook, která bude poskytovat soukromé služby, jako jsou fotogalerie, datové úložiště, zálohování nebo dohled nad domácností, a bude sloužit jako alternativa ke komerčním cloudovým službám. zpracujte, zrealizujte a zdokumentujte infrastrukturu obsahující alespoň jedno serverové (headless) a jedno klientské (gui) řešení postavené na linuxovém jádře. klientské řešení s gui bude svým zaměřením odpovídat pc pro počítačovou učebnu.
```

#### main points

```
alespoň jedna serverová a jedna klientská konfigurace
vhodný způsob správy hostů a zdůvodnění výběru technologií
bezpečný vzdálený přístup/připojení napříč hosty
vhodné centrální monitorování včetně notifikací při výpadku
proces nasazování aktualizovaných verzí systému
řešení záloh a obnovy dat
dokumentace řešení s doplněním o návod pro tvorbu obdobného, zjednodušeného řešení
```
