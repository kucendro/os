# KucendroOS

![plymoth](display/boot.png)

My NixOS / nix-darwin fleet — three Linux hosts (**nixbook**, **edge**, **nas**)
and a Mac (**mac**), meshed over a self-hosted Tailscale ([headscale][hs]) network.

## Architecture

The diagrams below are **auto-derived from the config** — never hand-drawn.
A [lefthook](lefthook.yml) pre-commit hook regenerates them on every change
(`nix run .#diagram`), so they can't drift from reality.
